# AdventureWorks data provenance and redistribution policy

## Sources reviewed (2026-10-20)

- Microsoft SQL Server samples repository: https://github.com/microsoft/sql-server-samples
- Microsoft repository MIT notice: https://github.com/microsoft/sql-server-samples/blob/master/license.txt
- Official AdventureWorks release, including `AdventureWorks2022.bak`: https://github.com/microsoft/sql-server-samples/releases/tag/adventureworks
- Microsoft installation documentation: https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure
- Microsoft SQL sample licensing overview: https://learn.microsoft.com/en-us/sql/samples/sql-samples-where-are

Microsoft describes the SQL Server samples and templates as MIT-licensed. Its official release distributes the AdventureWorks 2022 OLTP backup. The repository's MIT notice grants redistribution rights for covered materials when its copyright and permission notice are preserved.

**Interpretation, not a legal opinion:** These official sources provide a reasonable basis for public use of appropriately attributed AdventureWorks-derived analytical outputs. The root license refers to software, and a separate asset-specific grant for the backup's underlying data has not been located. Do not describe this as a legally guaranteed, asset-by-asset clearance.

## Separate ownership and data modes

1. **Microsoft-supplied AdventureWorks data:** Third-party sample content, not original work by this project. Identify source, version and Microsoft attribution. Do not imply endorsement.
2. **AdventureWorks-derived exports/charts:** Clearly identify as analysis of Microsoft's fictional sample business data, not actual business performance. Document derivation and preserve the applicable Microsoft notice alongside distributed substantial material.
3. **Project-created deterministic fictional fixture (`apps/web/data/demo.json`):** Public-safe demonstration fixture generated by this project's validation pipeline, **not actual AdventureWorks-derived records**. Label it as fictional wherever shown.
4. **Original source code and project documentation:** Separate licensing decision. Microsoft's MIT notice does not automatically license the original code in this repository.

## Publication rules

- Prefer publishing the existing deterministic fictional fixture for the hosted dashboard. This does not require distributing the real-source snapshot or backup.
- Do not commit or deploy the `.bak`, source Parquet snapshots, local DuckDB files, credentials, or full derived real-source exports by default.
- For any later public AdventureWorks-derived dataset: record exact upstream URL and version, acquisition date, transformation lineage, schema, row scope, hash, and publication purpose; review content for embedded third-party assets and identifiers; include the upstream Microsoft copyright and MIT permission notice with substantial redistributions; and review the specific publication artifact before release.
- For screenshots or charts, disclose whether they show deterministic fictional fixture results or historical AdventureWorks sample metrics. Avoid claims of production performance, recognized revenue, real customers, or live freshness.
- Retain links to the Microsoft source and license in the README, case study and any redistribution package.
- Do not claim the entire repository is MIT-licensed until the original project code license is independently selected.

## Release gate

**Current recommended release:** host `apps/web` using the checked-in fictional fixture, with clear disclosure and a link to this policy. This path does not depend on publishing Microsoft's backup or real-source export.

**If later publishing AdventureWorks-derived exports:** confirm the exact artifact and any asset-specific terms, carry the complete upstream license notice, document provenance, and obtain legal review if commercial or high-stakes redistribution certainty is required.

**Open separate decision:** select and add a license for this project's original code. Do not conflate code licensing with the Microsoft sample data terms.
